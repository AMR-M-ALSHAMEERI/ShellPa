# Security Policy

ShellPa turns natural-language requests into terminal commands, so safety and
privacy reports are treated as security reports.

## Supported versions

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use the repository's
[private vulnerability reporting](https://github.com/AMR-M-ALSHAMEERI/ShellPa/security/advisories/new)
flow. Include the affected version, operating system and shell, reproduction
steps, expected behavior, and the security or privacy impact. Remove API keys,
tokens, command output, usernames, and private file paths before submitting.

Reports involving command-policy bypasses, unsafe execution, credential
exposure, provider-context leakage, or recovery behavior are especially
important.
